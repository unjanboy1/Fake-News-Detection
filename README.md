# Fake News Detection System

The **Fake News Detection System** is a machine learning–based application designed to classify news articles as **real** or **fake** by analyzing their textual content. The project uses Natural Language Processing (NLP) techniques to preprocess news data, extract meaningful features, and train a classification model capable of identifying misleading or fabricated news with high accuracy.

The system performs text cleaning, tokenization, stop-word removal, and vectorization before feeding the processed data into a machine learning algorithm. After training, users can enter a news headline or article, and the model predicts whether the news is genuine or fake. The application provides a simple and user-friendly interface for quick and efficient news verification.

**Key Features:**

* Detection of fake and real news articles.
* Text preprocessing using NLP techniques.
* Machine learning–based classification.
* User-friendly interface for news input and prediction.
* Fast and accurate prediction results.
* Model training and evaluation using labeled datasets.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* NLTK
* TF-IDF Vectorizer
* Logistic Regression / Naive Bayes / Passive Aggressive Classifier
* Flask (optional for web deployment)

**Objective:**
The primary objective of this project is to help reduce the spread of misinformation by providing an automated system that analyzes news content and predicts its authenticity using machine learning and natural language processing techniques.
